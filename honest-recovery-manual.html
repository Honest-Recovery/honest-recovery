HonestRecovery

Complete guide to installing, setting up, and getting the most out of HonestRecovery for Mac.

HonestRecovery does three things exceptionally well:

🗑️
File Recovery
Recover deleted files from any Mac drive — even after the Trash has been emptied.
💾
Drive Cloning
Create a bit-for-bit clone of any drive for backup or migration purposes.
📱
iPhone Extraction
Pull contacts, messages, and photos directly off your iPhone.
ℹ️
One-time purchase

2 System Requirements

  • macOS 12 Monterey or later (Ventura, Sonoma, and Sequoia fully supported)
  • Mac with Apple Silicon (M1/M2/M3/M4)
  • At least 4 GB RAM recommended
  • Enough free disk space to save recovered files to (external drive strongly recommended)
  • Administrator access to grant required permissions

3 Installation

⚠️
macOS will flag this app — this is normal and expected.

Because HonestRecovery is sold directly (not through the Mac App Store), macOS Gatekeeper will warn you that it is from an "unidentified developer" the first time you open it. This does not mean the app is harmful. Follow the steps below to approve it.

Step 1 — Download & open the installer

  1. Download the .dmg file

    Save it anywhere — your Downloads folder is fine.

  2. Double-click the .dmg to mount it

    A window will appear showing the HonestRecovery app icon.

  3. Drag HonestRecovery into your Applications folder

    The window will have a shortcut arrow pointing to your Applications folder. Drag the icon across.

Step 2 — Approve the app in macOS Security settings

When you first try to open HonestRecovery, macOS will block it with a warning. Here is exactly what to do:

  1. Try to open HonestRecovery from your Applications folder

    A dialog will appear saying: "HonestRecovery cannot be opened because it is from an unidentified developer" or "Apple cannot verify that this app is free of malware."

  2. Click OK or Done to dismiss the warning

    Do not worry — this simply closes the dialog. The app has not been deleted.

  3. Open System Settings

    Click the Apple menu () in the top-left corner → System Settings

  4. Go to Privacy & Security

    Scroll down in the left sidebar and click Privacy & Security.

  5. Find the blocked app notice and click "Open Anyway"

    Scroll to the bottom of the Privacy & Security page. You will see a message saying HonestRecovery was blocked. Click Open Anyway.

  6. Enter your Mac password when prompted

    macOS requires your administrator password to approve the app.

  7. Click Open in the final confirmation dialog

    HonestRecovery will now launch. You will not need to repeat this process — the approval is saved permanently.

💡
Alternative: Right-click to open

Instead of step 1 above, you can right-click (or Control-click) the HonestRecovery icon in Applications and choose Open. A dialog will appear with an Open button that bypasses the block in one step.

🛡️
Using macOS Ventura or earlier?

On macOS Ventura and Monterey, Privacy & Security settings are in System Preferences (not System Settings). The location of the blocked app notice is identical — scroll to the bottom of the Security & Privacy pane and click Open Anyway.

How to grant Full Disk Access manually

⚠️
Full Disk Access is essential for recovery to work properly.

If HonestRecovery does not have Full Disk Access, it may scan but find zero recoverable files, or only find a fraction of what is actually there. Always grant this permission before running a scan.

  1. Open System Settings

    Apple menu () → System Settings

  2. Click Privacy & Security in the sidebar
  3. Scroll down and click Full Disk Access
  4. Click the + button and add HonestRecovery

    Navigate to your Applications folder, select HonestRecovery, and click Open.

  5. Make sure the toggle next to HonestRecovery is turned ON (blue)
  6. Restart HonestRecovery if it was already running

    Permissions take effect after a full quit and relaunch.

5 File Recovery

HonestRecovery can recover files that were deleted from a Mac drive — even if the Trash has been emptied, even after a drive has been reformatted (in many cases).

⚠️
Stop using the affected drive immediately.

Every file written to a drive after deletion can permanently overwrite the data you are trying to recover. As soon as you realize files are missing, stop using that drive and begin recovery as soon as possible.

Running a scan

  1. Open HonestRecovery and select File Recovery
  2. Select the drive or partition you want to scan

    All connected drives appear in the list. Choose the one where the files were lost.

  3. Choose Quick Scan or Deep Scan

    Quick Scan finds recently deleted files in seconds. Deep Scan performs a full sector-by-sector analysis and is recommended if Quick Scan finds nothing.

  4. Wait for the scan to complete

    Deep scans on large drives can take 30–90 minutes. Do not use the drive being scanned during this time.

  5. Browse the results and select files to recover

    Use the file type filters and search bar to find what you need.

  6. Click Recover and choose a save location

    Always save recovered files to a different drive than the one being scanned.

6 Drive Cloning

The Drive Cloning feature creates a byte-for-byte copy of any connected drive. Use it before upgrading to a new drive, to create a bootable backup, or to image a failing drive before attempting recovery.

⚠️
The destination drive will be completely erased.

Everything on the destination drive will be overwritten. Make sure you have selected the correct source and destination before starting. This cannot be undone.

  1. Connect both the source and destination drives

    The destination must be at least as large as the source.

  2. Open HonestRecovery and select Drive Cloning
  3. Set the Source drive

    The drive you want to copy from.

  4. Set the Destination drive

    The drive you want to copy to. Double-check this — it will be erased.

  5. Click Start Clone and confirm the warning
  6. Wait for the clone to complete

    Speed depends on drive size and connection type. Do not disconnect either drive during cloning.

7 iPhone Extraction

HonestRecovery can pull contacts, messages, and photos directly from a connected iPhone — no iCloud or iTunes backup required.

  1. Connect your iPhone via USB cable
  2. Unlock your iPhone and tap Trust on the "Trust This Computer?" prompt

    If you do not see this prompt, disconnect and reconnect the cable with your iPhone unlocked.

  3. Open HonestRecovery and select iPhone Extraction
  4. Select what to extract: Contacts, Messages, or Photos
  5. Click Extract and choose a save location
💡
iPhone not appearing?

Make sure you tapped Trust on your iPhone, and that you have granted HonestRecovery USB Accessories access in System Settings → Privacy & Security.

8 Troubleshooting

Below are the most common issues users run into and exactly how to fix them.

Very Common "Apple cannot verify this app" — app won't open ▶

This is macOS Gatekeeper blocking apps that were not downloaded from the Mac App Store. It is normal and does not mean the app is unsafe.

  1. Go to System Settings → Privacy & Security
  2. Scroll to the bottom of the page

    You will see "HonestRecovery was blocked from use because it is not from an identified developer."

  3. Click Open Anyway and enter your Mac password
  4. Click Open in the final confirmation
💡

Alternatively: right-click the app icon in Applications → Open → Open. This bypasses Gatekeeper in one step.

Very Common Scan completes but finds no files (or very few) ▶

This is almost always caused by missing Full Disk Access permission. The scan runs but cannot see protected areas of the drive.

  1. Quit HonestRecovery completely

    Command + Q, or right-click the Dock icon → Quit.

  2. Go to System Settings → Privacy & Security → Full Disk Access
  3. Confirm HonestRecovery is listed and its toggle is ON

    If it is not listed, click + and add it from your Applications folder.

  4. Relaunch HonestRecovery and run the scan again

If the problem persists after granting Full Disk Access, try a Deep Scan instead of a Quick Scan.

Common Drive not appearing in the drive list ▶

If an external drive is connected but not showing up inside HonestRecovery:

  1. Check if the drive appears in Finder or Disk Utility

    If it does not appear anywhere, the drive may have a hardware connection issue — try a different cable or port.

  2. Grant Removable Volumes access

    System Settings → Privacy & Security → Files and Folders → ensure HonestRecovery has access to Removable Volumes.

  3. Quit and relaunch HonestRecovery

    Then reconnect the drive.

  4. Try a different USB port or cable

    Faulty cables are a common cause of drives not being recognized.

Common Recovered files are corrupted or won't open ▶

File recovery is not always perfect. The data on disk may have been partially overwritten before the scan ran.

  • The sooner you run a scan after deletion, the higher the chance of full recovery.
  • Files deleted long ago, or on a drive used heavily since deletion, are more likely to be incomplete.
  • Try a Deep Scan if you ran a Quick Scan — it finds more fragments.
  • Some file formats (MP4, JPG, ZIP) are more recoverable than others due to how they store data.
Common iPhone not recognised or not appearing ▶
  1. Make sure your iPhone is unlocked when you connect it
  2. Tap Trust on the iPhone's "Trust This Computer?" prompt

    If you do not see it, disconnect, unlock the phone, and reconnect.

  3. Check System Settings → Privacy & Security → USB Accessories

    Make sure HonestRecovery is allowed.

  4. Try a different Lightning or USB-C cable

    Use Apple's original cable where possible — third-party cables sometimes block data transfer.

  5. Restart both the iPhone and HonestRecovery

    Then reconnect and try again.

Common Scan is very slow or appears stuck ▶

Deep scans on large drives (1 TB+) can take over an hour — this is normal.

  • The drive may have bad sectors — recovery tools slow down significantly when reading failing drives. Leave it running.
  • If the progress bar has not moved in over 30 minutes, try quitting and restarting the scan.
  • Avoid running other disk-intensive tasks (Time Machine, Spotlight indexing) during a scan.
  • On M1/M2/M3/M4 Macs with SSDs, Deep Scans are faster. On spinning hard drives or USB 2.0 drives, expect 1–3 hours for large drives.
Occasional Drive clone fails partway through ▶
  1. Check that the destination drive has enough space

    It must be at least as large as the used space on the source drive.

  2. Check both drive connections

    A loose cable during cloning will cause the operation to fail. Use a direct connection rather than a USB hub where possible.

  3. Check if the source drive is failing

    Open Disk Utility and run First Aid on the source drive. If it reports errors, the drive may be failing — complete the clone as soon as possible.

  4. Do not use the Mac for other tasks during cloning

    Keep the Mac plugged into power and let the clone run uninterrupted.

Occasional App crashes during a scan ▶
  1. Relaunch HonestRecovery

    In most cases the scan can be resumed or restarted without issue.

  2. Make sure macOS is up to date

    Apple menu → System Settings → General → Software Update.

  3. Free up RAM

    Close other heavy apps (browsers, video editors) before running a scan. Deep scans on very large drives can use significant memory.

  4. Contact support with the crash report

    If the crash is repeatable, send the crash log from: ~/Library/Logs/DiagnosticReports/

9 Tips & Best Practices

  • Always recover files to a different drive than the one being scanned. Saving to the same drive risks overwriting the very data you are recovering.
  • Run a scan as soon as possible after data loss. Every write to the drive reduces the chance of successful recovery.
  • Use Deep Scan if Quick Scan finds nothing. Quick Scan reads the file system table; Deep Scan reads every sector on the disk and is much more thorough.
  • Keep HonestRecovery up to date. Check the website periodically for new versions — updates are free for life.
  • If a drive is making unusual noises (clicking, grinding), stop using it immediately. This indicates physical failure — software recovery may not be possible and a specialist is recommended.
  • For failing drives, run the clone feature first to create an image, then attempt recovery from the clone rather than the failing original.
